# Animasyonlar ve Geçişler - Örnek Uygulama (v1)

**Takım:** TeamAnimators (6. Takım)

## Açıklama
Flutter'da animasyon türlerini gösteren üç sekmeli örnek uygulama:
- **Implicit:** `AnimatedContainer`, `AnimatedOpacity`
- **Explicit:** `AnimationController`, `ScaleTransition`, `RotationTransition`
- **Hero & Geçiş:** `Hero` animasyonu ve `PageRouteBuilder` ile özel sayfa geçişi

## Çalıştırma
```bash
flutter create .
# oluşan lib/main.dart yerine bu klasördeki main.dart dosyasını kullanın
flutter run
```
